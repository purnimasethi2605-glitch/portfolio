# Purnima Sethi

Economics graduate (Bachelor of Arts, Specialization in Economics, Western University, 2025) based in London, Ontario. I work with data to answer practical questions in economics, markets and small business.

This repository collects my analysis projects. Each folder has its own write up, the code, and the results the code produced.

## Projects

1. **[Energy prices: regression and forecasting](01_energy_prices_econometrics)** (R)
   How closely does the natural gas price follow the oil price, and can a time series model forecast oil better than a simple rule? OLS with Newey West standard errors, unit root and cointegration tests, ARIMA and ETS forecasts.

2. **[Does the toss decide the match?](02_cricket_toss_analysis)** (R)
   A course project on the 2024 T20 World Cup: do the toss decision, temperature, or day and night conditions change who wins? Linear probability models on 52 matches.

3. **[Outreach response rates for a small business](03_psol_outreach_analysis)** (R)
   Real reply data from my own import venture. Did one region respond better than the rest, and how sure can I be with a small sample?

4. **[Does timing matter when buying Bitcoin?](04_bitcoin_timing_analysis)** (Python)
   A test of a simple trend rule against buy and hold, and of investing all at once against monthly amounts, on daily prices since 2015.

5. **[Paper trading agent](05_trading_bot_paper_trading)** (Claude Code, Git)
   A learning project on how an automated AI agent is structured: rules, scheduled routines, and memory kept in files.

6. **[Resume tailoring workflow](06_resume_tailoring_workflow)** (Python, Claude)
   A keyword coverage checker and the workflow I use to tailor a resume to a job posting, with a human review step.
